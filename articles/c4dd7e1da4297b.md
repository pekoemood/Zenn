cn関数はshadow/cnに使われるclassNameを統合する便利な関数で
中身はclsx関数とtwMergeによって実装されている

clsxとは？？

判定処理などで発生したfalseなどをいらない記述を綺麗にしてくれる

たとえばclsx("px-4", "py-2", false && "bg-blue-500, { "text-blue-600": true} )
これを"px-4 py-2 text-blue-600"でかえしてくれる
*falsyな値を排除、オブジェクト( { "class":条件} )を処理してくれる

twMergeとは？？
tailwindによくあるクラスの競合を解決してくれる

たとえば、clsx("px-2", "px-4")
の場合、"px-4"を優先させたい時に使用する
twMerge("px-2", "px-4") → "px-4"

よくあるのが条件分岐による上書きなど
twMerge(clsx("px-2", "bg-blue-500", isError && "bg-red-500")) → "px-2 bg-red-500"
後勝ちの最適化をしてくれる！

最後にcva関数について
class-variance-authorityのライブラリで、スタイルのバリエーションを簡単に管理することができる
使い方は以下の通り

cva("px-2 py-4",
  {
    variants: {
      variant: {
        default: "bg-blue-500 text-white",
        outline: "border text-blue-500",
      },
      size: {
        sm: "px-3 py-1 text-sm",
        lg: "px-6 py-3 text-lg",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "sm",
    },
    compoundVariants: [
      {
        variant: "outline",
        size: "lg",
        class: "uppercase",
    },
    ]},
  );

  compoundVariantsはvariant: "outline"とsize: "lg"の時にclassに"uppercase"を追加する
