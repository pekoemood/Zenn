子クラスで親クラスのコンストラクトの呼び出し方

class A {
  private $name;
  private $age;

  public function __construct($name, $age) {
    $this->name = $name;
    $this->age = $age;
  }
}

class B extends A {
  private hobby;

  public function __construct($name, $age, $hobby) {
    parent::__construct($name, $age);
    $this->hobby = $hobby;
  }
}

parentを使用することで、親クラスのコンストラクトを使用できる

クラスメソッドの定義方法

class Menu {
  private $name;

  public function __construct($name) {
    $this->name = $name;
  }

  public function getName() {
    return $this->name;
  }

  public function setName($name) {
    $this->name = $name;
  }

  public static function getByGroup($group, $name) {
    foreach($group as $man) {
      if ($man->getName() == $name) {
        return $man;
      }
    }
  }
}

$man = Menu::getByGroup($group, $name);
