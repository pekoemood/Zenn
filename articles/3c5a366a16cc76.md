Next.jsの環境構築をdockerで行ったので、手順をまとめておく
まず環境構築用のディレクトリを作成する
今回の私はTodoアプリを作成したかったので、
mkdir todo-app
でディレクトリを作成した。

次にDockerfile, compose.ymlを作成
内容は以下の通り

ARG NODE_VER
#nodeの環境構築の内容を渡す変数を設定

FROM node:${NODE_VER}
#NODE_VERはここで渡す

USER node
#rootユーザーはトラブルのもとなので、nodeユーザーを作成

WORKDIR /home/node/app
#コンテナ内の作業スペースを作成、
正直 /appとかでもよいと思う

次に　compose.yml

services:
  app:
    container_name: app
    image: app:latest
    build:
      args:
        - NODE_VER=22-slim
      context: .
      dockerfile: Dockerfile
    tty: true
    stdin_open: true
    volumes:
      - type: bind
        source: ./app
        target: /home/node/app
    environment:
      - WATCHPACK_POLLING=true
    command: bash -c "npm run dev"
    ports:
      - "3001:3000"

特別な設定はないが、container_nameとimageで名前づけをしているのは判別しやすいから
volumesはショートハンドではなく、ロングハンドで記述している
この方がバインドかボリュームかもわかりやすいしおすすめ
また、今回知ったのだが、source ./appとしているとローカルに指定のディレクトリがなくても
compose upした時に自動で作成してくれた。。

environmentのWATCHPACI_POLLING=truはhorloaderのため
コンテナ内だとhotloaderが正しく機能しないことがあるが、polling設定をすることで、
変更内容がすぐに反映されるようになる
portsが3001としてるのは3000を別のアプリで使用しているため

以上の設定ができたら docker compose run -it --rm app bash
で一時的にコンテナを立ち上げる
npx create-npx-app@latest .
でカレントディレクトリにnext.jsの環境構築
バインドマウントにローカルに正しく反映されているのを確認して、
http://locaslhost:3001(普通は3000)を確認して
hotloaderが反映されているを確認したら環境構築は完了！！
