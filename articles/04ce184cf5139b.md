2月１日の学習にて

まず、Tailwindcss v4の導入にあたってdaisyuiを使用したかったことからcssbunding-railsを使用して導入を進めた
具体的にはcssbunding-railsをインストールしてrails css:tailwindでインポートした
その後にpackage.jsonからtailwindのバーションをv3に変更し、yarn add daisyuiでdaisyuiを
インストールしてプラグインで追加した。
なお、この追加した際にdaisyuiはダークモードが初期設定になっているため、バグかと少し焦った。。。

ようやく環境構築ができたと思ったら問題が発生！！
Tailwind css intellisenseが機能しない　つまり、予測変換が表示されないというバグが発生した
色々いじっくった結果表示されず。。
ネットを彷徨っていたところ、daisyuiの公式サイトでdaisyui version5betaが使用可能になった旨の
通知がありそこには　taillwindcss-railsのversion4.0.0の情報が！
公式の指示通りにインストールしたところ無事にtailwindcssV4およびdaiyuiの最新バージョンも使用可能となった

しかし！！まだ、Tailwindcssの予測補完が機能しない・・
しかしスタックオーバーフローにて機能しない理由はtailwind.css.configがrootディレクトリに存在しないことが
理由との記事を発見！！
touch tailwind.css.configで空のファイルを作成したところ補完が機能したのであった・・・

本日のまとめ　困った時は公式のサイトとsatackoverflowで検索しよう！！
