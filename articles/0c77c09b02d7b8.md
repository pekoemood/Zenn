BCryptGEMの主なメソッドについて

BCrypt::Password.create('ハッシュ化したい文字',cost: 'コストを指定する')
createメソッドは指定した文字とコストでハッシュ化したパスワードを生成する

BCrypt::Password.new(既存のハッシュ化されたオブジェクト)
ハッシュ化されたオブジェクトからBCrypt::Passwordオブジェクトを生成する
生成されたオブジェクトでパスワードの検証ができる

例えば。。。

code = BCrypt::Password.create('password',cost: BCrypt::Engine.cost)  *BCrypt::Engine.costは設定されているcostデフォルトでは12になっている
これでcodeにpasswordという文字列をハッシュ化したパスワードが入る

次にパスワードを検証する方法
password_object = BCrypt::Password.new(code)

password_object == 'password' # true
このように検証ができる

補足
BCrypt::Engine::MIN_COSTはBCryptがサポートする採用のcost値で'4'に設定されている
BCrypt::Engine::costは現在のcostを返し、defaultでは12に設定されている

is_pasword? 
これはBCrypt::Passwordのインスタンスメソッド
ハッシュ化されたパスワードと元のトークンを比較して正しければtrueを返す

例えば

password = BCrypt::Password.create('password', cost: 4)
check_password = BCrypt::Password.new(password)
check_password.is_password?('password') #true

これは検証ができる！！
ハッシュ化されたパスワードcheck_passwordが元のパスワード（'password')と一致するか確認できる
